Explaining how to install and run the Git hub..
1. Logged in my already exist git hub account.
2. Created a repository.
3. Initialized git into my vs code with a command (git init).
4. Created a file which is .gitignore into my workspace(vs code) inorder to ignore node_modules.
5. Entered a command (git add .) to add all the file.
6. Entered a command (git commit -m "message") to commit the files I want to push.
7. Enter a command (git remote add origin https://github.com/Oludent/Sequelize_Relationship.git) to know the repository the files are going.
8. Entered a command (git push -u origin master) cause the branch I wanted to push is master.
9. And lastly came to my github to refresh my repository and here are my files.
